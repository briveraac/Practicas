# Práctica de Ingeniería de Datos

Este repositorio documenta mi aprendizaje de ingeniería de datos, desde los fundamentos hasta la construcción de un pipeline de datos completo.

A través de ejercicios y proyectos pequeños, practicaré la lectura, limpieza, validación, almacenamiento, transformación y análisis de datos. Iré incorporando herramientas como Python, SQL, PostgreSQL, Docker, dbt, Airflow y Metabase a medida que avance.

## Proyecto inicial: análisis de ventas

El primer conjunto de ejercicios usa datos sintéticos de ventas. Trabajaré en detectar problemas de calidad —como duplicados, valores faltantes y formatos inconsistentes—, limpiar los registros y crear consultas para analizar ventas, productos, clientes y regiones.

## Objetivo final

Construir un pipeline reproducible que:

1. Reciba datos desde archivos o una fuente externa.
2. Valide y procese los registros con Python.
3. Almacene los datos en capas.
4. Transforme los datos con SQL y dbt.
5. Orqueste el flujo con Airflow.
6. Presente resultados mediante un dashboard en Metabase.

El proyecto se desarrollará progresivamente. Cada etapa incluirá su código, instrucciones para ejecutarlo y notas sobre los conceptos aprendidos. La versión inicial funcionará localmente; más adelante podré explorar su despliegue en AWS.
